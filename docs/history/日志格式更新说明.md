# 日志系统更新说明

## ✅ 已修复的问题

### 1. 日志文件后缀
**新的文件名格式**：`floatsort-YYYY-MM-DD.log`

示例：
```
logs/
├── floatsort-2025-10-31.log
├── floatsort-2025-11-01.log
└── floatsort-2025-11-02.log
```

**注意**：文件名从 `floatsort.YYYY-MM-DD` 改为 `floatsort-YYYY-MM-DD.log`
- 使用 `-` 连接符而不是 `.`
- 确保以 `.log` 结尾

### 2. 日志格式优化（去除🏷符号）

**之前的格式**（冗长）：
```
2025-11-01T12:34:56.123456Z  INFO floatsort::file_monitor: 监控根目录: 桌面
2025-11-01T12:34:57.234567Z  INFO floatsort::file_ops: ✓ 文件已整理
```

**现在的格式**（简洁）：
```
2025-11-01T12:34:56.123456Z  INFO 监控根目录: 桌面
2025-11-01T12:34:57.234567Z  INFO ✓ 文件已整理
```

**优化内容**：
- ✅ 移除模块路径 (floatsort::file_monitor)
- ✅ 移除线程ID
- ✅ 移除线程名
- ✅ 移除ANSI颜色代码
- ✅ 使用紧凑格式

## 📝 代码更改

### 文件名配置
```rust
let file_appender = RollingFileAppender::builder()
    .rotation(Rotation::DAILY)
    .filename_prefix("floatsort-")     // 使用 - 作为分隔符
    .filename_suffix(".log")           // 明确指定 .log 后缀
    .build("logs")
    .expect("无法初始化日志文件");
```

### 日志格式配置
```rust
tracing_subscriber::fmt()
    .with_env_filter(...)
    .with_writer(non_blocking)
    .with_target(false)         // 去掉模块路径
    .with_thread_ids(false)     // 去掉线程ID
    .with_thread_names(false)   // 去掉线程名
    .with_ansi(false)           // 去掉颜色代码
    .compact()                  // 紧凑格式
    .init();
```
