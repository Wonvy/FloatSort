## 🎯 截图规范

### 建议的截图尺寸
- **全屏截图**: 1920x1080 或 1280x720
- **窗口截图**: 保持原始大小
- **GIF 演示**: 不超过 5MB，帧率 10-15fps

### 文件命名规范
- 使用小写字母和连字符
- 描述性命名：`feature-description.png`
- 示例：`rule-editor-chinese.png`

### 图片格式
- **PNG**: 适合界面截图（无损）
- **JPG**: 适合照片类图片
- **GIF**: 适合短动画演示
- **WebP**: 体积更小（需要浏览器支持）

## 🔧 截图工具推荐

### Windows
- **Snipping Tool** / **Snip & Sketch** (Win+Shift+S)
- **ShareX** (免费，支持滚动截图)
- **LightShot** (快速截图)

### macOS
- **Command + Shift + 4** (区域截图)
- **Command + Shift + 5** (截图工具栏)

### 录制 GIF
- **ScreenToGif** (Windows)
- **LICEcap** (跨平台)
- **Gifox** (macOS)
